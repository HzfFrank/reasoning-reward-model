## 两套环境统一

v3 的几何、CoT、SFT 和初次 RLVR 串接使用 SOLE-R1 `reward_server/.venv`；V7 也已在同一环境完成双卡全参数 SFT 与真实推理。统一安装入口以官方 PyPI 补齐固定依赖，`--reuse` 在现有 SOLE-R1 环境验证通过；无需再为 v3 单独创建环境。

补充验证：SOLE-R1 环境读回先前独立环境导出的 v3 RLVR 模型，对 episode41 完成一次 from-zero 真实推理并严格解析成功。RLinf 环境独立负责仿真和策略训练。

## 共用 SOLE-R1 环境的补充实跑

在适配后的同一个 SOLE-R1 Python 中，从正式 v3 SFT 初始化，使用发布的 `scripts/train_rlvr.sh` 完成双卡 GRPO 1次更新与HF导出：奖励均值1.6616、格式通过率100%、非零组内优势。抽查视觉 patch 权重有93,340个值改变，语言第0层q_proj有76,655个值改变，证明更新实际写入导出模型。新导出的模型在同一环境重新加载并完成一次 from-zero GPU 推理，严格解析通过。

另使用未修改的 SOLE-R1 官方 `vlm_batch_decode` 与 vLLM 0.12.0 读取已发布 v3 RLVR 模型，sequential/from_zero 各预测2次，4次严格解析通过。使用本地已保存的processor，未调用会改写模型目录的官方loader；HTTP/RPC服务启动器未包含在测试中。
