# Third-party provenance

This repository contains the project's v7 experiment implementations and retained supporting modules. RL training and environment changes remain in the separate RLinf repository, with its existing license headers and history preserved. LIBERO source is separately obtained from RLinf/LIBERO at the revision recorded in environments/source_dependencies.json.

Qwen model assets and upstream Pi0 assets have their own licenses and are not included in this code repository. Do not infer a model or dataset license from the repository's visibility. This initial handoff has not assigned a new blanket license to all inherited code.

provenance/source_snapshot.json records source-file hashes before portability edits. Historical modules retained for dependencies are documented in docs/数据构造_CN.md.
